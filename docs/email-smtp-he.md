# מיילים למשתמשים (הרשמה, אישור מייל, איפוס סיסמה)

שירות המייל המובנה של Supabase שולח רק לחברי הצוות של הארגון ובקצב נמוך מאוד (כמה מיילים בשעה),
לכן כדי שכל אחד יוכל להירשם צריך SMTP משלך. שתי אפשרויות חינמיות:

## אפשרות א' – Resend (מומלץ, 3,000 מיילים בחודש / 100 ביום בחינם)
מה צריך ממך:
1. להירשם ב-resend.com (חינם).
2. דומיין שבבעלותך (למשל studioimage.co.il) ולהוסיף אצל ספק הדומיין את רשומות ה-DNS ש-Resend נותן (SPF/DKIM). בלי דומיין מאומת Resend שולח רק לכתובת שלך.
3. ליצור API Key ולהדביק אותו בתיבה המאובטחת (לא בצ'אט).
4. כתובת שולח, למשל no-reply@studioimage.co.il.
הגדרות SMTP שאני אגדיר: host smtp.resend.com, port 465, user `resend`, password = ה-API Key.

## אפשרות ב' – Gmail עם App Password (בלי דומיין, עד ~500 מיילים ביום)
מה צריך ממך:
1. אימות דו-שלבי פעיל בחשבון Google ששולח את המיילים.
2. ליצור App Password ב-https://myaccount.google.com/apppasswords (16 תווים) ולהדביק בתיבה המאובטחת.
3. כתובת ה-Gmail השולחת.
הגדרות: host smtp.gmail.com, port 465, user = כתובת ה-Gmail, password = ה-App Password.
חיסרון: המיילים יוצאים מכתובת Gmail פרטית, ולפעמים מגיעים לספאם.

אחרי שאקבל את הפרטים אגדיר אותם בפרויקט budget-app (Authentication → SMTP), אעלה את מגבלת המיילים לשעה ואתאים את נוסח מיילי האישור לעברית.
